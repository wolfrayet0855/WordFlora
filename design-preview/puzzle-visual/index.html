Puzzle screen: top 3 visual fixes

Static before/after mockups at iPhone 17 Pro size (402 x 874 pt). Before follows the current code (GameView, KeyboardView, WordTilesView); After applies V1-V3 from docs/pm/puzzle-experience-review.md. Toggle dark with the theme switch (theme.js) to see V3.

Before
⌂Level 5💡 Help
When a plant bends toward the light.
V1: PHOTOTROPISM (12 letters) at 30 pt tiles is 426 pt wide in a 362 pt column, so the last tiles fall off screen. V2: about 210 pt of empty cream (hatched) between the tiles and the keys. Title "Level 5" regular weight, off centre.
After
⌂Level 5💡 Help
Clue
When a plant bends toward the light.
V1: tile width = min(40, (column - gaps) / letters), here 25 pt; letters scale with it. V2: flower grows into the free space (170 to ~236 pt), clue/tiles on the 16 pt gutter, a "Clue" eyebrow, tiles 40 x 52 for short words. Title semibold and truly centred, Help reads as a button.
V3 key states before
Dark mode: white on #81C784 is 2.0:1. Used-wrong letters 2.3-2.7:1, 9 pt glyph. Rows have different key widths (33 / 37 / 39 pt) and no stagger.
V3 key states after
Correct key text #1A2E1A in dark (7.2:1), wrong letters at 70% (4.0-4.3:1), 11 pt glyph, one key width for every row (row 2 and 3 centred, so they stagger), 1 pt bottom shadow so keys lift off the cream.
