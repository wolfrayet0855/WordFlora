# Petal thinning: technique comparison

Evidence from the repo: the 50 plant SVGs are small, generated-looking files (0.9-10 KB; 616 KB for the whole catalog; imagesets set preserves-vector-representation). Petals are already separate elements. Daisy has 16 `<ellipse>` petals, each `rotate(n)` around the head centre. Tulip has 7 ellipses, sunflower about 45 circles and ellipses, lavender 58 ellipses. Cactus, baobab, flytrap and corpse flower have no petals (arms, trunk, traps, spathe).

Web research was thin. One search returned only generic drawingGroup/Canvas particle advice. Even-odd masks and wedge animation come from my own SwiftUI knowledge, UNVERIFIED against sources. No pages were fetched, so how Plant Nanny, Finch, Flora and Wylde Flowers show wilting is UNVERIFIED.

## 1. Hand-split petal layers
50 plants x (body + head + petal) plus per-plant placement. About 0.5-1 day of art per plant, so 25-50 days, redone on any redraw. Best look, worst cost. Not recommended.

## 2. Wedge masks over the existing image
Each wedge is a pie-slice `Shape` from the head centre. `Image(name).mask { WedgeSet(kept:).fill(style: FillStyle(eoFill: true)) }`, where even-odd is only needed for the "full rect minus wedges" form. A falling copy is the same Image masked to one wedge, then offset and rotated by keyframes. GPU cost is low (one offscreen mask pass on the head layer). Anti-aliasing: seams show a 1px halo, so overlap wedges 1-2 degrees.
Fatal flaw: a wedge cuts everything inside it (stem, leaves, neighbouring petals) and leaves a bite, not a bare head. Hiding it needs a redrawn centre disc per plant. It fails on non-radial plants (lavender, cactus). Not recommended.

## 3. Procedural generic head
Petals drawn as `Ellipse` shapes in the dominant colour. The original head would have to be hidden, which a flat image cannot do, and every plant loses its unique look. Not recommended.

## 4. Five pre-rendered states (250 images)
Cheap if the states are generated from the SVG source: dropping petal elements gives states 1-4 with no runtime masking (about 12 KB each, so under 1 MB extra for all). Falling petals still need one petal sprite per plant.

## 5. Type rules
- Flowers (about 30 plants) lose petals.
- Leafy plants (fern, aloe, clover, bamboo, Venus flytrap) lose leaves or traps. Trees lose leaves.
- Cactus, baobab, Joshua tree and lithops are exempt from loss and instead droop, desaturate or tilt.
- Tag each plant in `plants.json` with `thinKind: petals | leaves | exempt`.

## Recommendation: hybrid of 4 + 5, generated by script
Because petals are already separate SVG elements, one script (`tools/thin_svg.py`, not yet written) reads each SVG and finds petal or leaf elements (`ellipse` or `path` with a `rotate(...)` transform around the head centre). It writes `plant_X_t1..t4.svg`, dropping petals in a balanced order (alternating, not clustered), and `plant_X_petal.svg` for the falling sprite. Plants that do not match fall back to exempt (droop plus tint). Hand-fix about 6-8 odd ones (lavender, sunflower, strawberry).

State 5 is the bare head plus the existing `seed-pot.svg`.

- Effort: about 3-4 days for the script and QA, 1 day of hand fixes, 1.5 days of SwiftUI. About 6 days total.
- Art needs: none new.
- App size: about +0.7-1 MB.
- Regrow: reverse the fall (petal scales from 0) and crossfade t(n) to t(n-1).

## SwiftUI skeleton

```swift
struct ThinningPlant: View {
    let plant: Plant; let stage: Int // 0 full ... 4 bare
    @State private var falling: [Fall] = []
    var body: some View {
        ZStack {
            Image(plant.thinKind == .exempt ? plant.imageName : "\(plant.imageName)_t\(stage)")
                .resizable().scaledToFit()
                .id(stage).transition(.opacity)
            ForEach(falling) { f in
                Image("\(plant.imageName)_petal")
                    .keyframeAnimator(initialValue: FallState()) { v, s in
                        v.rotationEffect(s.angle).offset(s.offset).opacity(s.opacity)
                    } keyframes: { _ in
                        KeyframeTrack(\.offset) { LinearKeyframe(.init(width: f.dx, height: 140), duration: 1.6) }
                        KeyframeTrack(\.angle) { LinearKeyframe(.degrees(f.spin), duration: 1.6) }
                        KeyframeTrack(\.opacity) { LinearKeyframe(0, duration: 1.6) }
                    }
                    .position(f.start) // from headCenter + petalAngle in plants.json
            }
        }
        .animation(.easeInOut(duration: 0.6), value: stage)
        .onChange(of: stage) { old, new in if new > old { spawnFall() } }
    }
}
```

## Risks
- Pattern matching may catch leaf-like ellipses. Review a contact sheet of 50 plants x 5 states before shipping.
- Crossfading two states can ghost, so use short fades.
