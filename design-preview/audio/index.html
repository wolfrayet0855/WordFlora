WordFlora audio candidates

Original synthesized sounds (pure Python, no samples). 16 events, 3 variants each (badges: 3 tiers x 3 variants). 44.1 kHz 16-bit mono WAV, AAC .m4a also provided, peaks at -3 dBFS. Untested by ear: judge these on a device.

Recommended set (pinned)

Loudness: files are peak-normalized to -3 dBFS, which lands tonal sounds near -14 to -17 LUFS. Each clip lists the playback gain that brings it to about -20 LUFS; apply it as AVAudioPlayer.volume. Short clips under 0.4 s use an RMS-based estimate (marked ~). All sounds must follow the silent switch (AVAudioSession .ambient) and a Settings toggle. The existing sounds are audited in the notes at the bottom.
